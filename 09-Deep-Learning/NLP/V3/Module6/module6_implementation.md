## 💡 Applications Modernes

Découvrez comment les Transformers sont utilisés dans les modèles qui révolutionnent l'IA aujourd'hui.

#### 🤖 BERT (Bidirectional)

Modèle bidirectionnel pour la compréhension

*   Question-réponse
*   Classification de texte
*   Named Entity Recognition
*   Analyse de sentiment

#### ✍️ GPT (Génératif)

Modèle autorégressif pour la génération

*   Génération de texte
*   Complément de phrases
*   Rédaction automatique
*   Chatbots conversationnels

#### 🌍 T5 (Text-to-Text)

Toute tâche comme problème text-to-text

*   Traduction automatique
*   Résumé de texte
*   Paraphrase
*   Classification → texte

## 🎓 Ce que vous apprendrez

En suivant les notebooks d'implémentation, vous maîtriserez :

*   L'implémentation from scratch d'un Transformer
*   Les techniques d'optimisation pour l'entraînement (gradient clipping, warmup, etc.)
*   Le fine-tuning de modèles pré-entraînés (BERT, GPT)
*   Les méthodes de génération (beam search, sampling, top-k/top-p)
*   L'évaluation des modèles séquentiels (BLEU, ROUGE, perplexité)
*   La visualisation et l'interprétation des mécanismes d'attention
*   Le déploiement de Transformers en production
