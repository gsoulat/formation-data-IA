## 1. Conditions (if / elif / else)

Préférer la syntaxe `[[ ]]` (Bash/Zsh) à `[ ]` (POSIX).

```bash
if [[ $VAR == "test" ]]; then
    echo "Match"
elif [[ $VAR -gt 10 ]]; then
    echo "Supérieur à 10"
else
    echo "Autre"
fi
```

### Tests fréquents :
- `-f file` : Le fichier existe.
- `-d dir` : Le dossier existe.
- `-z str` : La chaîne est vide.

```bash
    echo "Traitement de $file"
done

# Sur une séquence
for i in {1..5}; do
    echo "Numéro $i"
done
```

## 3. Boucles (while / until)

```bash
# Lire un fichier ligne par ligne
while IFS= read -r line; do
    echo "Ligne : $line"
done < input.txt

# Attendre qu'un service soit prêt
until curl -s http://localhost:8080 > /dev/null; do
    sleep 5
done
```

## 4. Case statements (Switch)

```bash
case $filename in
    *.csv) echo "Type CSV" ;;
    *.json) echo "Type JSON" ;;
    *) echo "Inconnu" ;;
esac
```
